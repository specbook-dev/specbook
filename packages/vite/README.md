# @specbook/vite

The Specbook plugin for Vite: the registry, the docs UI hooks and the dev server credential proxy.

`@specbook/vite/internal` holds the project-file helpers the Specbook CLI uses; it is not a public API.

Part of [Specbook](https://github.com/specbook-dev/specbook), Storybook for APIs. See the repository for documentation.
